# kuerp 进销存 — 功能需求一览表

> 基于 FastAdmin + ThinkPHP 5.0 的进销存插件，覆盖采购、销售、仓库、资金四大核心模块。

---

## 一、数据面板

| 功能 | 说明 |
|------|------|
| Dashboard | 经营数据概览、图表统计 |
| 库存预警 | 低于/高于安全库存的商品提醒 |

---

## 二、购货管理

| 功能 | 说明 |
|------|------|
| 购货订单 | 向供应商下订单，审核后可转采购单 |
| 采购单 | 采购入库，审核后增加库存 |
| 购货退货单 | 退货出库，审核后冲减库存 |
| 采购明细表 | 按商品/时间查看采购记录 |
| 采购订单跟踪表 | 跟踪订单执行进度（已入库/未入库） |
| 采购汇总表(按商品) | 按商品汇总采购数量/金额 |
| 采购汇总表(按供应商) | 按供应商汇总采购金额 |
| 采购付款一览表 | 采购付款情况统计 |
| 采购开票管理 | 采购发票录入/管理 |
| 以销定购看板 | 根据销售数据建议采购量 |
| 智能补货 | 自动计算建议补货量 |
| 原始单据 | 采购相关附件管理 |

---

## 三、销货管理

| 功能 | 说明 |
|------|------|
| 销货订单 | 客户下单，审核后可转销货单 |
| 销货单 | 销售出库，审核后扣减库存、计算成本 |
| 销货退货单 | 客户退货入库，审核后恢复库存 |
| 销售订单跟踪表 | 跟踪订单执行进度 |
| 商品销售明细 | 按商品/时间查看销售记录 |
| 销货开票管理 | 销售发票录入/管理 |
| 销货收款一览表 | 销售收款情况统计 |
| 销售汇总表(按商品) | 按商品汇总销售数量/金额 |
| 销售汇总表(按客户) | 按客户汇总销售金额 |
| 销售汇总表(按销售员) | 按销售员汇总业绩 |
| 销售利润表 | 按单据计算毛利/毛利率/净利 |
| 销售排行表 | 按客户/商品销售排行 |
| 往来单位欠款表 | 客户/供应商欠款统计 |
| 原始单据 | 销售相关附件管理 |

---

## 四、仓库管理

| 功能 | 说明 |
|------|------|
| 调拨单 | 仓库间调货，审核后源仓减/目标仓增 |
| 成本调整单 | 调整商品加权平均成本 |
| 盘点单 | 盘盈/盘亏调整（支持导入/导出） |
| 序列号盘点 | 序列号商品盘点 |
| 其他入库单 | 非采购入库（盘盈、赠品等） |
| 其他出库单 | 非销售出库（盘亏、领用等） |
| 组装单 | 子件出库+成品入库，可保存模板 |
| 拆卸单 | 成品出库+子件入库，可保存模板 |
| 商品库存余额表 | 各仓库实时库存查询 |
| 批次跟踪表 | 按批次追踪出入库 |
| 商品收发明细表 | 按商品查看所有出入库流水 |
| 商品收发汇总表 | 按时间段汇总出入库 |
| 序列号跟踪表 | 序列号全流程追踪 |
| 序列号状态表 | 序列号当前状态（在库/出库/退货） |
| 批次保质期清单 | 批次保质期管理 |

---

## 五、资金管理

| 功能 | 说明 |
|------|------|
| 付款单 | 向供应商付款，审核后扣减账户余额 |
| 收款单 | 向客户收款，审核后增加账户余额 |
| 核销单 | 应收/应付款核销 |
| 应收账款明细表 | 客户欠款明细 |
| 应付账款明细表 | 供应商欠款明细 |
| 其他收入单 | 非销售收入入账 |
| 其他支出单 | 非采购支出入账 |
| 采购销售费用清单 | 采购/销售产生的费用管理 |
| 资金转账单 | 账户间资金转移 |
| 现金银行报表 | 各账户资金流水汇总 |
| 客户对账单 | 与客户的对账单 |
| 供应商对账单 | 与供应商的对账单 |
| 其他收支明细表 | 其他收支流水 |
| 利润表 | 经营利润统计 |

---

## 六、基础资料

| 功能 | 说明 |
|------|------|
| 客户管理 | 客户信息/分类/等级/价格体系 |
| 供应商管理 | 供应商信息/分类 |
| 商品管理 | 商品信息/分类/多单位/辅助属性/价格 |
| 仓库管理 | 仓库维护 |
| 账户管理 | 资金账户维护 |
| 职员管理 | 员工信息/销售员归属 |
| 发货地址管理 | 客户发货地址维护 |
| 辅助资料 | 分类/等级/单位/结算方式/辅助属性/客户物料编码 |

---

## 七、系统设置

| 功能 | 说明 |
|------|------|
| 系统参数 | 计价方式/小数位/含税开关/分仓核算等 |
| 系统初始化 | 清空业务数据，保留基础资料 |
| 结账/反结账 | 月度结账锁定，成本核算快照 |
| 编号规则(prefix) | 各单据编号前缀/流水号规则 |

---

## 八、石材小程序（扩展模块）

| 功能 | 说明 |
|------|------|
| 入库管理 | 石材采购入库，审核后增加库存 |
| 出库管理 | 石材销售出库，审核后扣减库存 |
| 库存查询 | 实时库存/累计出入库/库存金额 |
| 订货单 | 小程序订单审核/确认/发货/取消 |
| 轮播图 | 小程序首页轮播图管理 |
| 小程序配置 | 公告/协议/AppId 等 |
| 小程序用户 | 注册用户管理 |
