模板下载： 下载BOM导入模板

导入说明

1）父级商品编号必填，父级商品必须已在货品管理中创建；

2）子级商品至少填写一行，一行表示一个子级商品；

3）子级商品按"规格/规格2(厂商)/规格3(封装)"三参数匹配，三项完全一致才算匹配成功（双方均为空也视为一致）；部分相同须人工"替换"选择或"新增"；

4）同一父商品只能存在一个BOM模板。
